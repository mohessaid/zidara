# M0 + M1: Foundations and Kernel — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pure Rust kernel holding the six building blocks of a pedagogy, two frameworks (mastery and Cambridge-style), a governed assessment agent and command-replay sync, proven by unit, property, acceptance, coverage, mutation and four-target tests.

**Architecture:** `zidara-kernel` is a pure core: `decide(actor, command, history, env, ids) -> events` and `fold(events) -> state`, plus view intents. `zidara-frameworks` implements the `Framework` trait twice. `zidara-acceptance` runs Gherkin stories against both. No crate here does I/O; the server (M2) and the web shell (M3) wrap them.

**Tech Stack:** Rust 1.98 (edition 2024), serde, uuid (types only), thiserror, proptest, wasm-bindgen-test, cucumber 0.23, cargo-nextest, cargo-llvm-cov (nightly, `--branch`), cargo-mutants 27.

**Spec:** `docs/superpowers/specs/2026-10-14-zidara-prototype-design.md`

**Later plans:** M2 (server), M3 (shell), M4 (demo) each get their own plan when they start, written against the interfaces this plan produces.

## Global Constraints

- The kernel and frameworks crates depend on no database, async runtime, network, clock or randomness. They must build for `wasm32-unknown-unknown`, `aarch64-linux-android` and `aarch64-apple-ios`.
- `uuid` is used as a type only (`default-features = false, features = ["serde"]`); ids are generated by `IdGen` implementations in shells.
- Scores are integers in basis points (0–10 000). No floats anywhere in judgement.
- Mastery: mean of the last 3 attempts; achieved at ≥ 8 000; needs support below 6 000 after 2 attempts; remediation and a teacher notice below 6 000 after 2 attempts.
- Cambridge-style: bands are data (`beginning` 0, `developing` 4 000, `secure` 6 500, `excelling` 8 500 in the demo); expected rank 2; summative evidence judges, formative only shows a band; outcomes open by calendar.
- Agent policy: formative and confidence ≥ 8 500 → applied; otherwise queued; summative is never applied by an agent.
- Tests are written first. Every test file runs natively and on wasm32 (except acceptance, which is native only).
- Gates: 100% lines, functions and branches on kernel and frameworks; every cargo-mutants mutant caught or listed with a reason in `.cargo/mutants.toml`.
- Commit messages: short, plain, imperative, no prefixes, no AI attribution lines.
- Every task updates `CHANGELOG.md` (Unreleased) when it adds behaviour; notable events go in `docs/JOURNAL.md` (newest first).

## Review Focus

1. Arabic answers written with diacritics or tatweel ("نَضْرِبُ") must match a rubric term written without them ("ضرب"). Test in Task 6.
2. Fraction answers with a zero denominator or numbers near `u32::MAX` must be marked wrong or right without overflow or a false match (0/0 must not equal 1/2). Test in Task 5.
3. A double-tapped quiz submission is two attempts, and remediation is assigned once however many weak attempts follow. Test in Task 9 and the mastery feature.
4. Work synced late (older `at`) must land in time order, and the same command sent twice must count once. Tests in Task 8 (fold order) and the offline feature.
5. A studio view for an empty roster must report zeros without dividing by zero, and switching frameworks must lose no evidence. Tests in Task 10 and the framework-switch feature.

```rust path=crates/zidara-kernel/tests/support/mod.rs
use proptest::test_runner::{Config, RngAlgorithm, TestCaseError, TestRng, TestRunner};

/// Runs a property with a fixed seed: failures replay exactly, and wasm32 needs no file system.
pub fn check<S: Strategy>(strategy: S, test: impl Fn(S::Value) -> Result<(), TestCaseError>) {
    let config = Config { cases: 256, failure_persistence: None, ..Config::default() };
    let mut runner =
        TestRunner::new_with_rng(config, TestRng::deterministic_rng(RngAlgorithm::ChaCha));
    if let Err(failure) = runner.run(&strategy, test) {
        panic!("{failure}");
    }
}
```

```rust path=crates/zidara-kernel/src/score.rs
//! Scores in basis points. Integers keep judgement identical on every target.

use serde::{Deserialize, Serialize};

/// A score from 0 (nothing) to 10 000 (everything), in basis points.
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
#[serde(try_from = "u16", into = "u16")]
pub struct Score(u16);

/// Why a number is not a score.
#[derive(Clone, Copy, Debug, PartialEq, Eq, thiserror::Error)]
pub enum ScoreError {
    #[error("{0} basis points is above 10000")]
    OutOfRange(u16),
    #[error("{num}/{den} is above one")]
    FractionAboveOne { num: u32, den: u32 },
    #[error("a fraction cannot have a zero denominator")]
    ZeroDenominator,
}

impl Score {
    /// The highest score, in basis points.
    pub const MAX_BP: u16 = 10_000;
    pub const ZERO: Score = Score(0);
    pub const FULL: Score = Score(Self::MAX_BP);

    pub fn new(bp: u16) -> Result<Self, ScoreError> {
        if bp > Self::MAX_BP {
            return Err(ScoreError::OutOfRange(bp));
        }
        Ok(Self(bp))
    }

    /// For constants: a bad value fails at compile time, or panics in tests.
    pub const fn of(bp: u16) -> Self {
        assert!(bp <= Self::MAX_BP, "a score is at most 10000 basis points");
        Self(bp)
    }

    /// `num / den`, rounded half up.
    pub fn from_fraction(num: u32, den: u32) -> Result<Self, ScoreError> {
        if den == 0 {
            return Err(ScoreError::ZeroDenominator);
        }
        if num > den {
            return Err(ScoreError::FractionAboveOne { num, den });
        }
        let (num, den) = (u64::from(num), u64::from(den));
        Ok(Self(((num * u64::from(Self::MAX_BP) + den / 2) / den) as u16))
    }

    /// The mean, rounded half up; `None` when there is nothing to average.
    pub fn mean(scores: &[Score]) -> Option<Score> {
        if scores.is_empty() {
            return None;
        }
        let n = scores.len() as u64;
        let sum: u64 = scores.iter().map(|s| u64::from(s.0)).sum();
        Some(Self(((sum + n / 2) / n) as u16))
    }

    pub fn bp(self) -> u16 {
        self.0
    }
}

impl TryFrom<u16> for Score {
    type Error = ScoreError;
    fn try_from(bp: u16) -> Result<Self, Self::Error> {
        Self::new(bp)
    }
}

impl From<Score> for u16 {
    fn from(score: Score) -> u16 {
        score.0
    }
}
```

```bash path=scripts/branch-gate.sh
#!/usr/bin/env bash
# Fails unless every branch recorded in an lcov file was taken.
set -euo pipefail
lcov="${1:?usage: branch-gate.sh <lcov.info>}"
read -r found hit < <(awk -F: '/^BRF:/{f+=$2} /^BRH:/{h+=$2} END{print f+0, h+0}' "$lcov")
echo "branches: ${hit}/${found}"
if [ "$found" -ne "$hit" ]; then
  echo "uncovered branches:" >&2
  awk -F'[:,]' '/^SF:/{file=$2} /^BRDA:/ && ($5=="-" || $5=="0"){print file":"$2}' "$lcov" | sort -u >&2

fi
```

```rust path=crates/zidara-kernel/src/outcome.rs
//! Outcomes: what a learner should be able to do, as a graph of prerequisites.

use std::collections::BTreeSet;

use serde::{Deserialize, Serialize};

use crate::ids::OutcomeId;
use crate::locale::Localized;

/// One outcome, in the shape CASE frameworks use (id, title, what it builds on).
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Outcome {
    pub id: OutcomeId,
    pub title: Localized,
    #[serde(default)]
    pub prerequisites: Vec<OutcomeId>,
}

#[derive(Clone, Debug, PartialEq, Eq, thiserror::Error)]
pub enum GraphError {
    #[error("outcome {0:?} appears twice")]
    Duplicate(OutcomeId),
    #[error("outcome {outcome:?} needs unknown outcome {missing:?}")]
    UnknownPrerequisite { outcome: OutcomeId, missing: OutcomeId },
    #[error("outcome {:?} is part of a prerequisite cycle", .0.as_str())]
    Cycle(OutcomeId),
}

/// Outcomes ordered so every prerequisite comes before the outcomes that need it.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct OutcomeGraph {
    outcomes: Vec<Outcome>,
}

impl OutcomeGraph {
    pub fn new(outcomes: Vec<Outcome>) -> Result<Self, GraphError> {
        let mut ids = BTreeSet::new();
        for outcome in &outcomes {
            if !ids.insert(outcome.id.clone()) {
                return Err(GraphError::Duplicate(outcome.id.clone()));
            }
        }
        for outcome in &outcomes {
            if let Some(missing) = outcome.prerequisites.iter().find(|p| !ids.contains(*p)) {
                return Err(GraphError::UnknownPrerequisite {
                    outcome: outcome.id.clone(),
                    missing: missing.clone(),
                });
            }
        }
        // Repeatedly take the first outcome whose prerequisites are all placed.
        let mut placed = BTreeSet::new();
        let mut remaining = outcomes;
        let mut ordered = Vec::with_capacity(remaining.len());
        while !remaining.is_empty() {
            let Some(next) =
                remaining.iter().position(|o| o.prerequisites.iter().all(|p| placed.contains(p)))
            else {
                return Err(GraphError::Cycle(remaining[0].id.clone()));
            };
            let outcome = remaining.remove(next);
            placed.insert(outcome.id.clone());
            ordered.push(outcome);
        }
        Ok(Self { outcomes: ordered })
    }

    pub fn get(&self, id: &OutcomeId) -> Option<&Outcome> {
        self.outcomes.iter().find(|o| &o.id == id)
    }

    pub fn iter(&self) -> impl Iterator<Item = &Outcome> {
        self.outcomes.iter()
    }

    pub fn len(&self) -> usize {
        self.outcomes.len()
    }

    pub fn is_empty(&self) -> bool {
        self.outcomes.is_empty()
    }
}
```

```rust path=crates/zidara-kernel/src/roles.rs
//! Roles: who may do what. People and agents go through the same table.

use serde::{Deserialize, Serialize};

use crate::ids::{AgentId, UserId};

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Role {
    Learner,
    Teacher,
    AssessmentAgent,
    System,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Permission {
    SubmitWork,
    RecordFormative,
    RecordSummative,
    ProposeAssessment,
    DecideProposal,
    Undo,
    ChangeFramework,
}

/// The permission table. Agents may propose and record formative marks, nothing more.
pub fn allows(role: Role, permission: Permission) -> bool {
    use Permission::*;
    matches!(
        (role, permission),
        (Role::Learner, SubmitWork)
            | (Role::Teacher, RecordFormative | RecordSummative | DecideProposal | Undo | ChangeFramework)
            | (Role::AssessmentAgent, ProposeAssessment | RecordFormative)
            | (Role::System, RecordFormative | RecordSummative)
    )
}

/// Whoever caused an event.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum Actor {
    Human { user: UserId, role: Role },
    Agent { agent: AgentId, role: Role },
    System,
}

impl Actor {
    pub fn role(&self) -> Role {
        match self {
            Actor::Human { role, .. } | Actor::Agent { role, .. } => *role,
            Actor::System => Role::System,
        }
    }

    pub fn can(&self, permission: Permission) -> bool {
        allows(self.role(), permission)
    }
}
```

```rust path=crates/zidara-kernel/src/activity.rs
//! Activities: what a learner does, and how a quiz is marked.

use serde::{Deserialize, Serialize};

use crate::evidence::EvidenceKind;
use crate::governance::Rubric;
use crate::ids::{ActivityId, OutcomeId};
use crate::locale::Localized;
use crate::score::Score;

/// The right answer to a question.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum Expected {
    Choice { options: Vec<Localized>, correct: u32 },
    /// This fraction in exactly this form (e.g. 2/4, not 1/2).
    Exactly { num: u32, den: u32 },
    /// Any fraction equal to this one.
    EquivalentTo { num: u32, den: u32 },
}

/// A learner's answer to a question.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum Response {
    Choice { index: u32 },
    Fraction { num: u32, den: u32 },
}

impl Expected {
    pub fn accepts(&self, response: &Response) -> bool {
        match (self, response) {
            (Expected::Choice { correct, .. }, Response::Choice { index }) => index == correct,
            (Expected::Exactly { num, den }, Response::Fraction { num: n, den: d }) => {
                n == num && d == den
            }
            (Expected::EquivalentTo { num, den }, Response::Fraction { num: n, den: d }) => {
                *d != 0 && u64::from(*n) * u64::from(*den) == u64::from(*num) * u64::from(*d)
            }
            _ => false,
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Question {
    pub id: String,
    pub outcome: OutcomeId,
    pub prompt: Localized,
    pub expected: Expected,
}

/// Core activities are the lesson; remediation is offered when a learner struggles.
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ActivityRole {
    #[default]
    Core,
    Remediation,
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ActivityKind {
    Video {
        src: String,
        seconds: u32,
    },
    Reading {
        body: Localized,
        #[serde(default)]
        audio: Option<String>,
    },
    Quiz {
        evidence: EvidenceKind,
        questions: Vec<Question>,
    },
    OpenResponse {
        evidence: EvidenceKind,
        outcome: OutcomeId,
        prompt: Localized,
        rubric: Rubric,
    },
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Activity {
    pub id: ActivityId,
    pub title: Localized,
    pub outcomes: Vec<OutcomeId>,
    #[serde(default)]
    pub role: ActivityRole,
    pub kind: ActivityKind,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, thiserror::Error)]
#[error("expected {expected} responses, got {got}")]
pub struct MarkError {
    pub expected: usize,
    pub got: usize,
}

/// Marks a quiz: one score per outcome, in the order outcomes first appear.
pub fn mark(questions: &[Question], responses: &[Response]) -> Result<Vec<(OutcomeId, Score)>, MarkError> {
    if questions.len() != responses.len() {
        return Err(MarkError { expected: questions.len(), got: responses.len() });
    }
    let mut tally: Vec<(OutcomeId, u32, u32)> = Vec::new();
    for (question, response) in questions.iter().zip(responses) {
        let right = u32::from(question.expected.accepts(response));
        match tally.iter_mut().find(|(outcome, _, _)| *outcome == question.outcome) {
            Some(entry) => {
                entry.1 += right;
                entry.2 += 1;
            }
            None => tally.push((question.outcome.clone(), right, 1)),
        }
    }
    // right <= total and total >= 1 by construction, so the fraction is always valid.
    Ok(tally
        .into_iter()
        .map(|(outcome, right, total)| (outcome, Score::from_fraction(right, total).unwrap_or(Score::ZERO)))
        .collect())
}
```

```rust path=crates/zidara-kernel/src/governance.rs
//! Governance: how an agent's marking is weighed before it touches a learner's record.

use serde::{Deserialize, Serialize};

use crate::evidence::EvidenceKind;
use crate::ids::{ActivityId, EventId, OutcomeId, UserId};
use crate::score::Score;

/// One thing a good answer mentions; any of the terms counts.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Criterion {
    pub any_of: Vec<String>,
    pub weight: u16,
}

/// What a teacher looks for in an open answer.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Rubric {
    pub criteria: Vec<Criterion>,
    pub min_words: u16,
}

/// A mark with how sure the marker is.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Assessment {
    pub score: Score,
    pub confidence: Score,
    pub rationale: String,
}

/// All criteria met, or none: easy to call.
pub const CLEAR: Score = Score::of(9_000);
/// Some criteria met: a teacher should look.
pub const MIXED: Score = Score::of(6_000);
/// Too few words to judge.
pub const TOO_SHORT: Score = Score::of(4_000);

/// Deterministic first-pass marking against a rubric. Used offline, in tests, and as the
/// fallback when no model is configured.
pub fn assess(rubric: &Rubric, answer: &str) -> Assessment {
    let text = normalize(answer);
    let total: u32 = rubric.criteria.iter().map(|c| u32::from(c.weight)).sum();
    let met: Vec<&Criterion> = rubric
        .criteria
        .iter()
        .filter(|c| c.any_of.iter().any(|term| text.contains(&normalize(term))))
        .collect();
    let matched: u32 = met.iter().map(|c| u32::from(c.weight)).sum();
    let score = Score::from_fraction(matched, total).unwrap_or(Score::ZERO);
    let words = answer.split_whitespace().count();
    let confidence = if words < usize::from(rubric.min_words) {
        TOO_SHORT
    } else if matched == 0 || matched == total {
        CLEAR
    } else {
        MIXED
    };
    let rationale = format!("met {} of {} criteria in {} words", met.len(), rubric.criteria.len(), words);
    Assessment { score, confidence, rationale }
}

/// Lower case, without Arabic short vowels (U+064B–U+0652) or tatweel (U+0640).
fn normalize(text: &str) -> String {
    text.to_lowercase()
        .chars()
        .filter(|c| !matches!(c, '\u{064B}'..='\u{0652}' | '\u{0640}'))
        .collect()
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Decision {
    Apply,
    Queue,
}

/// When an agent's mark may be applied without a person.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Policy {
    pub auto_apply_at: Score,
}

impl Policy {
    pub const STANDARD: Policy = Policy { auto_apply_at: Score::of(8_500) };

    /// Formative and confident: apply. Anything else, summative above all: a teacher decides.
    pub fn decide(&self, kind: EvidenceKind, assessment: &Assessment) -> Decision {
        if kind == EvidenceKind::Formative && assessment.confidence >= self.auto_apply_at {
            Decision::Apply
        } else {
            Decision::Queue
        }
    }
}

/// An agent's mark for one answer, with what the policy decided.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Proposal {
    pub answer: EventId,
    pub learner: UserId,
    pub outcome: OutcomeId,
    pub activity: ActivityId,
    pub kind: EvidenceKind,
    pub assessment: Assessment,
    pub decision: Decision,
}
```

```rust path=crates/zidara-kernel/src/lesson.rs
//! Lessons: outcomes and activities, checked once when loaded.

use std::collections::BTreeSet;

use serde::Deserialize;

use crate::activity::{Activity, ActivityKind, ActivityRole, Expected};
use crate::ids::{ActivityId, OutcomeId};
use crate::locale::Localized;
use crate::outcome::{GraphError, Outcome, OutcomeGraph};

#[derive(Clone, Debug, PartialEq, Eq, thiserror::Error)]
pub enum LessonError {
    #[error(transparent)]
    Graph(#[from] GraphError),
    #[error("activity {0:?} appears twice")]
    DuplicateActivity(ActivityId),
    #[error("activity {activity:?} refers to unknown outcome {outcome:?}")]
    UnknownOutcome { activity: ActivityId, outcome: OutcomeId },
    #[error("question {question} in {activity:?} has no option {correct}")]
    BadChoice { activity: ActivityId, question: String, correct: u32 },
}

/// A lesson pack as stored in `content/lessons/*.json`, before it is checked.
#[derive(Deserialize)]
struct LessonPack {
    id: String,
    title: Localized,
    outcomes: Vec<Outcome>,
    activities: Vec<Activity>,
}

/// A checked lesson: every reference resolves.
#[derive(Clone, Debug, PartialEq, Eq, Deserialize)]
#[serde(try_from = "LessonPack")]
pub struct Lesson {
    pub id: String,
    pub title: Localized,
    pub graph: OutcomeGraph,
    activities: Vec<Activity>,
}

impl TryFrom<LessonPack> for Lesson {
    type Error = LessonError;
    fn try_from(pack: LessonPack) -> Result<Self, Self::Error> {
        Lesson::new(pack.id, pack.title, pack.outcomes, pack.activities)
    }
}

impl Lesson {
    pub fn new(
        id: impl Into<String>,
        title: Localized,
        outcomes: Vec<Outcome>,
        activities: Vec<Activity>,
    ) -> Result<Self, LessonError> {
        let graph = OutcomeGraph::new(outcomes)?;
        let mut seen = BTreeSet::new();
        for activity in &activities {
            if !seen.insert(activity.id.clone()) {
                return Err(LessonError::DuplicateActivity(activity.id.clone()));
            }
            if let Some(missing) = referenced_outcomes(activity).into_iter().find(|o| graph.get(o).is_none()) {
                return Err(LessonError::UnknownOutcome { activity: activity.id.clone(), outcome: missing.clone() });
            }
            if let ActivityKind::Quiz { questions, .. } = &activity.kind {
                for question in questions {
                    if let Expected::Choice { options, correct } = &question.expected
                        && *correct as usize >= options.len()
                    {
                        return Err(LessonError::BadChoice {
                            activity: activity.id.clone(),
                            question: question.id.clone(),
                            correct: *correct,
                        });
                    }
                }
            }
        }
        Ok(Self { id: id.into(), title, graph, activities })
    }

    pub fn activity(&self, id: &ActivityId) -> Option<&Activity> {
        self.activities.iter().find(|a| &a.id == id)
    }

    pub fn activities(&self) -> &[Activity] {
        &self.activities
    }

    /// The first remediation activity covering `outcome`, if the lesson has one.
    pub fn remediation_for(&self, outcome: &OutcomeId) -> Option<&Activity> {
        self.activities.iter().find(|a| a.role == ActivityRole::Remediation && a.outcomes.contains(outcome))
    }
}

fn referenced_outcomes(activity: &Activity) -> Vec<&OutcomeId> {
    let mut refs: Vec<&OutcomeId> = activity.outcomes.iter().collect();
    match &activity.kind {
        ActivityKind::Quiz { questions, .. } => refs.extend(questions.iter().map(|q| &q.outcome)),
        ActivityKind::OpenResponse { outcome, .. } => refs.push(outcome),
        ActivityKind::Video { .. } | ActivityKind::Reading { .. } => {}
    }
    refs
}
```

```rust path=crates/zidara-kernel/src/framework.rs
//! The framework contract: judgement and progression. Each pedagogy implements it once.

use std::collections::BTreeMap;
use std::fmt::Debug;

use serde::{Deserialize, Serialize};

use crate::evidence::Evidence;
use crate::ids::{FrameworkId, OutcomeId, Timestamp};
use crate::outcome::OutcomeGraph;
use crate::rules::Rule;
use crate::score::Score;

/// Where a learner stands on one outcome. Experiences decide how to draw it.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum OutcomeState {
    NotStarted,
    InProgress,
    Achieved,
    NeedsSupport,
}

/// A named level. `rank` counts from 0 (lowest) to `of - 1`; a label is a translation key.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Band {
    pub label: String,
    pub rank: u8,
    pub of: u8,
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Judgement {
    pub state: OutcomeState,
    pub score: Option<Score>,
    pub band: Option<Band>,
    pub attempts: u32,
}

impl Judgement {
    pub const NOT_STARTED: Judgement =
        Judgement { state: OutcomeState::NotStarted, score: None, band: None, attempts: 0 };
}

/// Why an outcome is not open yet.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum LockReason {
    Prerequisite { outcome: OutcomeId },
    OpensAt { at: Timestamp },
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Availability {
    pub outcome: OutcomeId,
    pub lock: Option<LockReason>,
}

/// What progression may look at.
#[derive(Clone, Copy, Debug)]
pub struct ProgressContext<'a> {
    pub graph: &'a OutcomeGraph,
    pub judgements: &'a BTreeMap<OutcomeId, Judgement>,
    pub now: Timestamp,
}

impl ProgressContext<'_> {
    pub fn state_of(&self, outcome: &OutcomeId) -> OutcomeState {
        self.judgements.get(outcome).map_or(OutcomeState::NotStarted, |j| j.state)
    }
}

/// A pedagogy made explicit. Data (thresholds, bands, calendars) lives in the implementation;
/// the kernel only calls these four functions.
pub trait Framework: Debug {
    fn id(&self) -> FrameworkId;
    /// Judges one learner on one outcome from that outcome's evidence, oldest first.
    fn judge(&self, evidence: &[&Evidence]) -> Judgement;
    /// For each outcome in graph order: open, or why not.
    fn availability(&self, ctx: &ProgressContext<'_>) -> Vec<Availability>;
    /// Automation the framework asks for.
    fn rules(&self) -> &[Rule];
}

/// Finds frameworks by id. Shells hold the registry; the kernel only reads it.
pub trait FrameworkRegistry: Debug {
    fn get(&self, id: &FrameworkId) -> Option<&dyn Framework>;
}
```

```rust path=crates/zidara-kernel/src/rules.rs
//! Rules: automation a framework asks for, evaluated as a pure function.

use serde::{Deserialize, Serialize};

use crate::framework::Judgement;
use crate::score::Score;

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum Rule {
    /// Below `below` after `after_attempts` tries: offer remediation and tell the teacher.
    Remediate { below: Score, after_attempts: u32 },
    /// A band below `rank`: tell the teacher early.
    NotifyBelowRank { rank: u8 },
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum NotifyReason {
    Struggling,
    BelowExpected,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Action {
    Remediate,
    NotifyTeacher(NotifyReason),
}

pub fn evaluate(rules: &[Rule], judgement: &Judgement) -> Vec<Action> {
    let mut actions = Vec::new();
    for rule in rules {
        match *rule {
            Rule::Remediate { below, after_attempts } => {
                if judgement.attempts >= after_attempts && judgement.score.is_some_and(|s| s < below) {
                    actions.push(Action::Remediate);
                    actions.push(Action::NotifyTeacher(NotifyReason::Struggling));
                }
            }
            Rule::NotifyBelowRank { rank } => {
                if judgement.band.as_ref().is_some_and(|b| b.rank < rank) {
                    actions.push(Action::NotifyTeacher(NotifyReason::BelowExpected));
                }
            }
        }
    }
    actions
}
```

```rust path=crates/zidara-kernel/src/state.rs
//! The fold: what is true now, computed from the log.

use std::collections::{BTreeMap, BTreeSet};

use serde::{Deserialize, Serialize};

use crate::event::{Event, EventBody};
use crate::evidence::Evidence;
use crate::governance::{Decision, Proposal};
use crate::ids::{ActivityId, EventId, FrameworkId, OutcomeId, UserId};
use crate::roles::Actor;
use crate::rules::NotifyReason;

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ProposalStatus {
    Applied,
    Queued,
    Accepted,
    Rejected,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Answer {
    pub learner: UserId,
    pub activity: ActivityId,
    pub text: String,
}

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct CohortState {
    pub framework: Option<FrameworkId>,
    /// Oldest first, with who recorded each piece.
    pub evidence: Vec<(EventId, Actor, Evidence)>,
    pub answers: BTreeMap<EventId, Answer>,
    pub proposals: BTreeMap<EventId, (Proposal, ProposalStatus)>,
    pub assignments: BTreeMap<EventId, (UserId, OutcomeId, ActivityId)>,
    pub notifications: BTreeSet<(UserId, OutcomeId, NotifyReason)>,
}

impl CohortState {
    pub fn evidence_for(&self, learner: UserId, outcome: &OutcomeId) -> Vec<&Evidence> {
        self.evidence
            .iter()
            .map(|(_, _, e)| e)
            .filter(|e| e.learner == learner && &e.outcome == outcome)
            .collect()
    }

    pub fn is_assigned(&self, learner: UserId, outcome: &OutcomeId, activity: &ActivityId) -> bool {
        self.assignments.values().any(|(l, o, a)| *l == learner && o == outcome && a == activity)
    }

    pub fn has_proposal_for(&self, answer: EventId) -> bool {
        self.proposals.values().any(|(p, _)| p.answer == answer)
    }
}

/// Folds a log into state. Events are ordered by `at` (a stable sort, so events from one
/// command keep their order), and undone events are skipped.
pub fn fold(events: &[Event]) -> CohortState {
    let mut ordered: Vec<&Event> = events.iter().collect();
    ordered.sort_by_key(|e| e.at);
    let undone: BTreeSet<EventId> = ordered
        .iter()
        .filter_map(|e| match e.body {
            EventBody::Undone { target } => Some(target),
            _ => None,
        })
        .collect();
    let mut state = CohortState::default();
    for event in ordered.into_iter().filter(|e| !undone.contains(&e.id)) {
        match &event.body {
            EventBody::EvidenceRecorded { evidence } => {
                state.evidence.push((event.id, event.actor.clone(), evidence.clone()));
            }
            EventBody::AnswerSubmitted { learner, activity, answer } => {
                state.answers.insert(
                    event.id,
                    Answer { learner: *learner, activity: activity.clone(), text: answer.clone() },
                );
            }
            EventBody::ProposalMade { proposal } => {
                let status = match proposal.decision {
                    Decision::Apply => ProposalStatus::Applied,
                    Decision::Queue => ProposalStatus::Queued,
                };
                state.proposals.insert(event.id, (proposal.clone(), status));
            }
            EventBody::ProposalDecided { proposal, accept } => {
                if let Some(entry) = state.proposals.get_mut(proposal) {
                    entry.1 = if *accept { ProposalStatus::Accepted } else { ProposalStatus::Rejected };
                }
            }
            EventBody::ActivityAssigned { learner, outcome, activity } => {
                state.assignments.insert(event.id, (*learner, outcome.clone(), activity.clone()));
            }
            EventBody::TeacherNotified { learner, outcome, reason } => {
                state.notifications.insert((*learner, outcome.clone(), *reason));
            }
            EventBody::FrameworkChanged { framework } => state.framework = Some(framework.clone()),
            EventBody::QuizSubmitted { .. } | EventBody::Undone { .. } => {}
        }
    }
    state
}
```

```rust path=crates/zidara-kernel/src/decide.rs
//! decide: the kernel's one entry point for change.
//!
//! Given who acts, what they ask and what has happened, it returns the new events or says
//! why not. It is pure: the same inputs give the same events on the server and on a phone.

use serde::{Deserialize, Serialize};

use crate::activity::{Activity, ActivityKind, Response, mark};
use crate::event::{Event, EventBody};
use crate::evidence::{Evidence, EvidenceKind};
use crate::framework::{Framework, FrameworkRegistry};
use crate::governance::{Assessment, Decision, Policy, Proposal};
use crate::ids::{
    ActivityId, CohortId, EventId, FrameworkId, IdGen, OutcomeId, TenantId, Timestamp, UserId, Uuid,
};
use crate::lesson::Lesson;
use crate::roles::{Actor, Permission, Role};
use crate::rules::{Action, evaluate};
use crate::score::Score;
use crate::state::{CohortState, ProposalStatus, fold};

#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum Command {
    SubmitQuiz { activity: ActivityId, responses: Vec<Response> },
    SubmitAnswer { activity: ActivityId, answer: String },
    RecordEvidence { learner: UserId, outcome: OutcomeId, activity: ActivityId, score: Score, kind: EvidenceKind },
    ProposeAssessment { answer: EventId, assessment: Assessment },
    DecideProposal { proposal: EventId, accept: bool },
    Undo { target: EventId },
    ChangeFramework { framework: FrameworkId },
}

/// A command as a shell sends it. `id` makes a retry harmless; `at` is when the person acted.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Envelope {
    pub id: Uuid,
    pub at: Timestamp,
    pub command: Command,
}

/// Everything a decision depends on besides the log. Shells build one per request.
#[derive(Clone, Copy, Debug)]
pub struct Env<'a> {
    pub now: Timestamp,
    pub tenant: TenantId,
    pub cohort: CohortId,
    pub lesson: &'a Lesson,
    pub frameworks: &'a dyn FrameworkRegistry,
    pub default_framework: &'a FrameworkId,
    pub policy: Policy,
}

#[derive(Clone, Debug, PartialEq, Eq, thiserror::Error, Serialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum KernelError {
    #[error("{role:?} may not {permission:?}")]
    Forbidden { role: Role, permission: Permission },
    #[error("only a person can submit work")]
    NotAPerson,
    #[error("unknown activity {activity:?}")]
    UnknownActivity { activity: ActivityId },
    #[error("activity {activity:?} does not take this kind of work")]
    WrongActivityKind { activity: ActivityId },
    #[error("unknown outcome {outcome:?}")]
    UnknownOutcome { outcome: OutcomeId },
    #[error("expected {expected} responses, got {got}")]
    Responses { expected: usize, got: usize },
    #[error("no answer {answer:?}")]
    UnknownAnswer { answer: EventId },
    #[error("answer {answer:?} already has a proposal")]
    AlreadyProposed { answer: EventId },
    #[error("no open proposal {proposal:?}")]
    NotOpen { proposal: EventId },
    #[error("event {target:?} cannot be undone")]
    NotUndoable { target: EventId },
    #[error("unknown framework {framework:?}")]
    UnknownFramework { framework: FrameworkId },
}

pub fn decide(
    actor: &Actor,
    command: Command,
    history: &[Event],
    env: &Env<'_>,
    ids: &mut dyn IdGen,
) -> Result<Vec<Event>, KernelError> {
    let mut batch = Batch { history, env, ids, events: Vec::new() };
    match command {
        Command::SubmitQuiz { activity, responses } => submit_quiz(&mut batch, actor, activity, responses)?,
        Command::SubmitAnswer { activity, answer } => submit_answer(&mut batch, actor, activity, answer)?,
        Command::RecordEvidence { learner, outcome, activity, score, kind } => {
            record_evidence(&mut batch, actor, Evidence { learner, outcome, activity, score, kind })?
        }
        Command::ProposeAssessment { answer, assessment } => propose(&mut batch, actor, answer, assessment)?,
        Command::DecideProposal { proposal, accept } => decide_proposal(&mut batch, actor, proposal, accept)?,
        Command::Undo { target } => undo(&mut batch, actor, target)?,
        Command::ChangeFramework { framework } => change_framework(&mut batch, actor, framework)?,
    }
    Ok(batch.events)
}

/// The class's framework, or the default when nobody has chosen one.
pub fn current_framework<'a>(state: &CohortState, env: &Env<'a>) -> Result<&'a dyn Framework, KernelError> {
    let id = state.framework.as_ref().unwrap_or(env.default_framework);
    env.frameworks.get(id).ok_or_else(|| KernelError::UnknownFramework { framework: id.clone() })
}

/// The events one command produces, built on top of the history.
struct Batch<'a, 'i> {
    history: &'a [Event],
    env: &'a Env<'a>,
    ids: &'i mut dyn IdGen,
    events: Vec<Event>,
}

impl Batch<'_, '_> {
    fn push(&mut self, actor: Actor, body: EventBody) -> EventId {
        let id = self.ids.next_id();
        let env = self.env;
        self.events.push(Event { id, at: env.now, tenant: env.tenant, cohort: env.cohort, actor, body });
        id
    }

    fn state(&self) -> CohortState {
        let all: Vec<Event> = self.history.iter().chain(&self.events).cloned().collect();
        fold(&all)
    }

    /// Records evidence, then runs the framework's rules for that learner and outcome.
    fn record(&mut self, actor: Actor, evidence: Evidence) -> Result<(), KernelError> {
        let (learner, outcome) = (evidence.learner, evidence.outcome.clone());
        self.push(actor, EventBody::EvidenceRecorded { evidence });
        let state = self.state();
        let framework = current_framework(&state, self.env)?;
        let judgement = framework.judge(&state.evidence_for(learner, &outcome));
        for action in evaluate(framework.rules(), &judgement) {
            match action {
                Action::Remediate => {
                    if let Some(activity) = self.env.lesson.remediation_for(&outcome)
                        && !state.is_assigned(learner, &outcome, &activity.id)
                    {
                        let activity = activity.id.clone();
                        self.push(Actor::System, EventBody::ActivityAssigned { learner, outcome: outcome.clone(), activity });
                    }
                }
                Action::NotifyTeacher(reason) => {
                    if !state.notifications.contains(&(learner, outcome.clone(), reason)) {
                        self.push(Actor::System, EventBody::TeacherNotified { learner, outcome: outcome.clone(), reason });
                    }
                }
            }
        }
        Ok(())
    }
}

fn require(actor: &Actor, permission: Permission) -> Result<(), KernelError> {
    if actor.can(permission) { Ok(()) } else { Err(KernelError::Forbidden { role: actor.role(), permission }) }
}

fn person(actor: &Actor) -> Result<UserId, KernelError> {
    match actor {
        Actor::Human { user, .. } => Ok(*user),
        _ => Err(KernelError::NotAPerson),
    }
}

fn permission_to_record(kind: EvidenceKind) -> Permission {
    match kind {
        EvidenceKind::Formative => Permission::RecordFormative,
        EvidenceKind::Summative => Permission::RecordSummative,
    }
}

fn activity<'a>(env: &Env<'a>, id: &ActivityId) -> Result<&'a Activity, KernelError> {
    env.lesson.activity(id).ok_or_else(|| KernelError::UnknownActivity { activity: id.clone() })
}

fn submit_quiz(b: &mut Batch<'_, '_>, actor: &Actor, id: ActivityId, responses: Vec<Response>) -> Result<(), KernelError> {
    require(actor, Permission::SubmitWork)?;
    let learner = person(actor)?;
    let ActivityKind::Quiz { evidence: kind, questions } = &activity(b.env, &id)?.kind else {
        return Err(KernelError::WrongActivityKind { activity: id });
    };
    let marks = mark(questions, &responses).map_err(|e| KernelError::Responses { expected: e.expected, got: e.got })?;
    b.push(actor.clone(), EventBody::QuizSubmitted { learner, activity: id.clone(), responses });
    for (outcome, score) in marks {
        b.record(Actor::System, Evidence { learner, outcome, activity: id.clone(), score, kind: *kind })?;
    }
    Ok(())
}

fn submit_answer(b: &mut Batch<'_, '_>, actor: &Actor, id: ActivityId, answer: String) -> Result<(), KernelError> {
    require(actor, Permission::SubmitWork)?;
    let learner = person(actor)?;
    if !matches!(activity(b.env, &id)?.kind, ActivityKind::OpenResponse { .. }) {
        return Err(KernelError::WrongActivityKind { activity: id });
    }
    b.push(actor.clone(), EventBody::AnswerSubmitted { learner, activity: id, answer });
    Ok(())
}

fn record_evidence(b: &mut Batch<'_, '_>, actor: &Actor, evidence: Evidence) -> Result<(), KernelError> {
    require(actor, permission_to_record(evidence.kind))?;
    if b.env.lesson.graph.get(&evidence.outcome).is_none() {
        return Err(KernelError::UnknownOutcome { outcome: evidence.outcome });
    }
    activity(b.env, &evidence.activity)?;
    b.record(actor.clone(), evidence)
}

fn propose(b: &mut Batch<'_, '_>, actor: &Actor, answer: EventId, assessment: Assessment) -> Result<(), KernelError> {
    require(actor, Permission::ProposeAssessment)?;
    let state = b.state();
    let Some(submitted) = state.answers.get(&answer) else {
        return Err(KernelError::UnknownAnswer { answer });
    };
    if state.has_proposal_for(answer) {
        return Err(KernelError::AlreadyProposed { answer });
    }
    let ActivityKind::OpenResponse { evidence: kind, outcome, .. } = &activity(b.env, &submitted.activity)?.kind else {
        return Err(KernelError::WrongActivityKind { activity: submitted.activity.clone() });
    };
    // The permission table already forbids agents summative marks; the policy never applies them.
    let decision = b.env.policy.decide(*kind, &assessment);
    let proposal = Proposal {
        answer,
        learner: submitted.learner,
        outcome: outcome.clone(),
        activity: submitted.activity.clone(),
        kind: *kind,
        assessment: assessment.clone(),
        decision,
    };
    b.push(actor.clone(), EventBody::ProposalMade { proposal });
    if decision == Decision::Apply {
        let evidence = Evidence {
            learner: submitted.learner,
            outcome: outcome.clone(),
            activity: submitted.activity.clone(),
            score: assessment.score,
            kind: *kind,
        };
        b.record(actor.clone(), evidence)?;
    }
    Ok(())
}

fn decide_proposal(b: &mut Batch<'_, '_>, actor: &Actor, proposal: EventId, accept: bool) -> Result<(), KernelError> {
    require(actor, Permission::DecideProposal)?;
    let state = b.state();
    let Some((open, ProposalStatus::Queued)) = state.proposals.get(&proposal) else {
        return Err(KernelError::NotOpen { proposal });
    };
    b.push(actor.clone(), EventBody::ProposalDecided { proposal, accept });
    if accept {
        let evidence = Evidence {
            learner: open.learner,
            outcome: open.outcome.clone(),
            activity: open.activity.clone(),
            score: open.assessment.score,
            kind: open.kind,
        };
        b.record(actor.clone(), evidence)?;
    }
    Ok(())
}

fn undo(b: &mut Batch<'_, '_>, actor: &Actor, target: EventId) -> Result<(), KernelError> {
    require(actor, Permission::Undo)?;
    let state = b.state();
    let undoable = state.evidence.iter().any(|(id, _, _)| *id == target) || state.assignments.contains_key(&target);
    if !undoable {
        return Err(KernelError::NotUndoable { target });
    }
    b.push(actor.clone(), EventBody::Undone { target });
    Ok(())
}

fn change_framework(b: &mut Batch<'_, '_>, actor: &Actor, framework: FrameworkId) -> Result<(), KernelError> {
    require(actor, Permission::ChangeFramework)?;
    if b.env.frameworks.get(&framework).is_none() {
        return Err(KernelError::UnknownFramework { framework });
    }
    b.push(actor.clone(), EventBody::FrameworkChanged { framework });
    Ok(())
}
```

```rust path=crates/zidara-kernel/tests/view.rs
        .collect();
```

```rust path=crates/zidara-kernel/src/view.rs
        .notifications
        .iter()
```

```rust path=crates/zidara-frameworks/src/mastery.rs
//! Mastery learning (Bloom): move on when you show the outcome, not when the calendar says.

use zidara_kernel::evidence::Evidence;
use zidara_kernel::framework::{
    Availability, Band, Framework, Judgement, LockReason, OutcomeState, ProgressContext,
};
use zidara_kernel::ids::FrameworkId;
use zidara_kernel::rules::Rule;
use zidara_kernel::score::Score;

pub const ID: &str = "mastery";

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Mastery {
    /// The mean of recent tries that counts as mastered.
    pub threshold: Score,
    /// Below this after `support_after` tries, a learner needs support.
    pub support_below: Score,
    pub support_after: u32,
    /// How many recent tries count.
    pub window: usize,
    rules: Vec<Rule>,
}

impl Mastery {
    /// 80% over the last three tries; support and remediation below 60% after two.
    pub fn standard() -> Self {
        Self {
            threshold: Score::of(8_000),
            support_below: Score::of(6_000),
            support_after: 2,
            window: 3,
            rules: vec![Rule::Remediate { below: Score::of(6_000), after_attempts: 2 }],
        }
    }
}

impl Framework for Mastery {
    fn id(&self) -> FrameworkId {
        FrameworkId::new(ID)
    }

    fn judge(&self, evidence: &[&Evidence]) -> Judgement {
        let attempts = evidence.len() as u32;
        let recent: Vec<Score> = evidence.iter().rev().take(self.window).map(|e| e.score).collect();
        let Some(score) = Score::mean(&recent) else { return Judgement::NOT_STARTED };
        let (state, rank, label) = if score >= self.threshold {
            (OutcomeState::Achieved, 2, "mastery.mastered")
        } else if score >= self.support_below {
            (OutcomeState::InProgress, 1, "mastery.developing")
        } else if attempts >= self.support_after {
            (OutcomeState::NeedsSupport, 0, "mastery.not_yet")
        } else {
            (OutcomeState::InProgress, 0, "mastery.not_yet")
        };
        Judgement { state, score: Some(score), band: Some(Band { label: label.into(), rank, of: 3 }), attempts }
    }

    fn availability(&self, ctx: &ProgressContext<'_>) -> Vec<Availability> {
        ctx.graph
            .iter()
            .map(|o| Availability {
                outcome: o.id.clone(),
                lock: o
                    .prerequisites
                    .iter()
                    .find(|p| ctx.state_of(p) != OutcomeState::Achieved)
                    .map(|p| LockReason::Prerequisite { outcome: p.clone() }),
            })
            .collect()
    }

    fn rules(&self) -> &[Rule] {
        &self.rules
    }
}
```

```rust path=crates/zidara-frameworks/src/cambridge.rs
/// A grade boundary: scores at or above `min` earn `label` (a translation key).
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Boundary {
    pub label: String,
    pub min: Score,
}

#[derive(Clone, Debug, PartialEq, Eq, thiserror::Error)]
pub enum BoundaryError {
    #[error("at least one boundary is needed")]
    Empty,
    #[error("the first boundary must start at zero")]
    FirstNotZero,
    #[error("boundaries must rise strictly")]
    NotRising,
    #[error("expected rank {0} is past the last boundary")]
    ExpectedOutOfRange(u8),
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct CambridgeStyle {
    boundaries: Vec<Boundary>,
    expected_rank: u8,
    opens_at: BTreeMap<OutcomeId, Timestamp>,
    rules: Vec<Rule>,
}

impl CambridgeStyle {
    pub fn new(
        boundaries: Vec<Boundary>,
        expected_rank: u8,
        opens_at: BTreeMap<OutcomeId, Timestamp>,
    ) -> Result<Self, BoundaryError> {
        let Some(first) = boundaries.first() else { return Err(BoundaryError::Empty) };
        if first.min != Score::ZERO {
            return Err(BoundaryError::FirstNotZero);
        }
        if boundaries.windows(2).any(|pair| pair[1].min <= pair[0].min) {
            return Err(BoundaryError::NotRising);
        }
        if usize::from(expected_rank) >= boundaries.len() {
            return Err(BoundaryError::ExpectedOutOfRange(expected_rank));
        }
        let rules = vec![Rule::NotifyBelowRank { rank: expected_rank }];
        Ok(Self { boundaries, expected_rank, opens_at, rules })
    }

    /// Four bands for a primary checkpoint; "secure" is expected.
    pub fn primary_checkpoint(opens_at: BTreeMap<OutcomeId, Timestamp>) -> Self {
        let b = |label: &str, min| Boundary { label: label.into(), min: Score::of(min) };
        let bands = vec![
            b("cambridge.beginning", 0),
            b("cambridge.developing", 4_000),
            b("cambridge.secure", 6_500),
            b("cambridge.excelling", 8_500),
        ];
        Self::new(bands, 2, opens_at).expect("the demo boundaries are valid")
    }

    fn band(&self, score: Score) -> Band {
        // The first boundary starts at zero, so some boundary always matches.
        let rank = self.boundaries.iter().rposition(|b| score >= b.min).unwrap_or(0);
        Band { label: self.boundaries[rank].label.clone(), rank: rank as u8, of: self.boundaries.len() as u8 }
    }
}

impl Framework for CambridgeStyle {
    fn id(&self) -> FrameworkId {
        FrameworkId::new(ID)
    }

    fn judge(&self, evidence: &[&Evidence]) -> Judgement {
        let summative: Vec<Score> =
            evidence.iter().filter(|e| e.kind == EvidenceKind::Summative).map(|e| e.score).collect();
        let all: Vec<Score> = evidence.iter().map(|e| e.score).collect();
        let basis = if summative.is_empty() { &all } else { &summative };
        let Some(score) = Score::mean(basis) else { return Judgement::NOT_STARTED };
        let band = self.band(score);
        let state = if summative.is_empty() {
            OutcomeState::InProgress
        } else if band.rank >= self.expected_rank {
            OutcomeState::Achieved
        } else {
            OutcomeState::NeedsSupport
        };
        Judgement { state, score: Some(score), band: Some(band), attempts: evidence.len() as u32 }
    }

    fn availability(&self, ctx: &ProgressContext<'_>) -> Vec<Availability> {
        ctx.graph
            .iter()
            .map(|o| Availability {
                outcome: o.id.clone(),
                lock: self.opens_at.get(&o.id).filter(|at| ctx.now < **at).map(|at| LockReason::OpensAt { at: *at }),
            })
            .collect()
    }

    fn rules(&self) -> &[Rule] {
        &self.rules
    }
}
```

```rust path=crates/zidara-acceptance/tests/acceptance.rs
fn env<'a>(lesson: &'a Lesson, registry: &'a Registry, framework: &'a FrameworkId, now: Timestamp) -> Env<'a> {

        cohort: CohortId(Uuid::from_u128(2)),
        lesson,
        frameworks: registry,
        default_framework: framework,

impl Class {
    fn new() -> Self {
        let opens_at = [("F1", 0), ("F2", 1), ("F3", 2)]
            .into_iter()
            .map(|(o, week)| (OutcomeId::new(o), Timestamp(TERM_START + week * WEEK)))

                .expect("the demo lesson is valid"),

            framework: FrameworkId::new("mastery"),
            now: Timestamp(TERM_START + HOUR),
            people: BTreeMap::new(),

            server_ids: SequentialIds::default(),
            applied: BTreeSet::new(),
            sent: vec![],
            phone: None,
            phone_log: None,
            commands: 0,
            refused: None,
        }
    }

    fn actor(&self, name: &str) -> Actor {
        self.people.get(name).cloned().unwrap_or_else(|| panic!("{name} was not introduced"))
    }

    fn user(&self, name: &str) -> UserId {
        match self.actor(name) {
            Actor::Human { user, .. } => user,
            other => panic!("{name} is not a person: {other:?}"),
        }
    }

    /// Runs a command where the actor is: on the offline phone, or on the server.
    fn try_run(&mut self, name: &str, command: Command) -> Result<(), KernelError> {
        let actor = self.actor(name);
        self.commands += 1;
        let envelope = Envelope { id: Uuid::from_u128(self.commands), at: self.now, command };
        if let Some(mut phone) = self.phone.take() {
            let env = env(&self.lesson, &self.registry, &self.framework, envelope.at);
            let result = decide(&actor, envelope.command.clone(), &phone.log, &env, &mut phone.ids);
            if let Ok(events) = &result {
                phone.log.extend(events.iter().cloned());
                phone.outbox.push((actor, envelope));
            }
            self.phone = Some(phone);
            return result.map(|_| ());
        }
        self.apply(&actor, envelope)
    }

    fn run(&mut self, name: &str, command: Command) {
        self.try_run(name, command).unwrap_or_else(|e| panic!("{name} was refused: {e}"));
    }

    /// What the server does with an envelope: once per id, at the time the person acted.
    fn apply(&mut self, actor: &Actor, envelope: Envelope) -> Result<(), KernelError> {
        if !self.applied.insert(envelope.id) {
            return Ok(());
        }
        let at = Timestamp(envelope.at.0.min(self.now.0));
        let env = env(&self.lesson, &self.registry, &self.framework, at);
        let events = decide(actor, envelope.command, &self.server, &env, &mut self.server_ids)?;
        self.server.extend(events);
        Ok(())
    }

    fn view_on(&self, log: &[Event], name: &str) -> LearnerView {
        learner_view(self.user(name), "en", log, &env(&self.lesson, &self.registry, &self.framework, self.now)).unwrap()
    }

    fn view(&self, name: &str) -> LearnerView {
        self.view_on(&self.server, name)
    }

    fn outcome(&self, name: &str, outcome: &str) -> zidara_kernel::view::OutcomeView {
        self.view(name).outcomes.into_iter().find(|o| o.outcome.as_str() == outcome).unwrap()
    }

    fn quiz(&self, activity: &str, right: usize, total: usize) -> Command {
        let Some(ActivityKind::Quiz { questions, .. }) = self.lesson.activity(&ActivityId::new(activity)).map(|a| &a.kind)
        else {
            panic!("{activity} is not a quiz")
        };
        assert_eq!(questions.len(), total, "{activity} has {} questions", questions.len());
        let responses = questions
            .iter()
            .enumerate()
            .map(|(i, q)| match (&q.expected, i < right) {
                (Expected::Choice { correct, .. }, true) => Response::Choice { index: *correct },
                (Expected::Choice { correct, .. }, false) => Response::Choice { index: correct + 1 },
                (Expected::Exactly { num, den }, true) => Response::Fraction { num: *num, den: *den },
                // An equivalent form, so marking is exercised, not just copied.
                (Expected::EquivalentTo { num, den }, true) => Response::Fraction { num: num * 2, den: den * 2 },
                (_, false) => Response::Fraction { num: 0, den: 1 },
            })
            .collect();
        Command::SubmitQuiz { activity: ActivityId::new(activity), responses }
    }

    fn latest_proposal(&self) -> (EventId, zidara_kernel::state::ProposalStatus) {
        let state = fold(&self.server);
        let (id, (_, status)) = state.proposals.iter().next_back().expect("a proposal exists");
        (*id, *status)
    }
}
```
